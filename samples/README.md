# Sanitized demo outputs

These samples describe verified synthetic rehearsals. They contain no real customer data, credentials, session capabilities, internal subject/thread/event IDs or local machine paths.

The Markdown files are simplified, sanitized presentations of saved canonical outputs, not byte-identical exports. Their memory versions refer to the original rehearsal; their bytes cannot be used to reproduce its canonical hash. The JSON is a demonstration summary, not a raw API response.

- [Buyer memory](buyer.md): voice correction and chat recall, memory v3.
- [Seller memory](seller.md): voice correction followed by a confirmed chat edit, memory v4.
- [Journey summary](journeys.json): before/after facts and evidence provenance.

## Add screenshots or a recording

Capture the chat reply, preparation panel, memory version and publication status. Tool arguments/results can establish confirmation and acceptance. Hide bearer values, session capabilities, API keys, session IDs, signed connection URLs and any real customer identifiers. Do not include `.env` or `artifacts/voice-demo/session.json`.

Use opaque redaction or crop before export; check the saved image. Store only reviewed images in this directory. Label the data as synthetic and distinguish actual outputs from these adapted samples.
